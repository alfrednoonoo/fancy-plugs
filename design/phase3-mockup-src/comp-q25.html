1 · EDIT drawer, Detector tab
The drawer keeps its size (524 × 374) and place over the main grid. A view switch sits in its title row, after "EDIT": Detector | Character | Upward | Options. It isn't a parameter; the drawer opens on the last tab used (per editor, not saved). The response curve shows the whole detector chain: the main layout's Highpass and Lowpass (dimmer) and the three new bands (blue, the colour of the detector filters on the main layout). A band at 0 dB is bypassed and its knobs dim its handle on the curve. Auto threshold shows its current offset next to it while on.

Every knob is the shared small Knob (tight style), so typed values come with it: Freq takes 3000 or 3k. Gain is bipolar. The curve's handles drag Freq and Gain (and the wheel sets the bell's Q), as in Fancy EQ, but the curve is only a picture of the detector: it never changes the audio path.
2 · EDIT drawer, Character tab
Type and Position are shared ParamSegments. Drive is a medium knob in the teal of the main grid. The small graph draws the transfer curve f(d·x)/d for the current Type and Drive (input −24 to +6 dBFS on both axes, the unity line dashed), so the knee moving down as Drive rises is visible. With Type Off, Position and Drive dim, as Comp's other dependent controls do.

3 · EDIT drawer, Upward tab
The controls and order of MultiComp's Upward row (Phase 2.1 U), as small knobs. The transfer curve shows the whole static curve, downward and upward, with Threshold and Up threshold marked, and a white dot at the current detector level and its gain (Decision 2 A: the GR meter keeps showing reduction only). The lift region is green, the reduction region teal. With Upward off, the four knobs dim and the curve shows the downward part alone.

5 · Threshold meter: the effective threshold while Auto threshold is on
The only change on the main layout. ThresholdMeter gets an option for a second marker: a thin 2 px line in white at 60 % across the bars, at Threshold + offset, moving as the offset follows the material. The handle stays where the user set Threshold, and dragging or typing still sets Threshold. Off, the meter is today's; Gate doesn't use the option.
Left: Auto threshold on, Threshold −24 dB, offset +6.0 dB, so the effective threshold sits at −18.0 dB. Right: Auto threshold off, today's meter.
