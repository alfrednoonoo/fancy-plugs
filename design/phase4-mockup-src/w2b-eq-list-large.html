Fancy EQ: v1.7.2 mockup (the band list in a large window)

Drawn on the real screenshot of the largest window (1800 x 1300 and its title strip), with twelve bands. The graph is squeezed to its new height to show the space it keeps; in the plugin it redraws, so its text and handles stay round. Changed area in dashed yellow.
1 · A (recommended): the list grows with its rows, and the columns spread up to 1100 px, centred
With List on, the list is as tall as its rows need, taking height from the graph, which never gets shorter than it is at the default size (344 px). Six rows or fewer look as today; here twelve bands show, and from about 1040 px tall all 24 do. The columns spread from 734 px up to 1100 px wide and stay centred, so a row stays easy to read across. No control changes size.

3 · The default window (802 x 645): unchanged in both
The graph is already at its smallest, so the list keeps its six rows and scrolls, and 734 px is the columns' normal width.
The strip is 178 px in Bands at every size, so switching between Bands and List moves the graph's bottom edge only when the list is taller. Adding a seventh band or more makes the list 22 px taller while there's room. Compact mode still has no list. No parameter changes.
