Fancy EQ: Phase 4 mockup, band list and groups (item 46, layout approval)

docs/eq.md, Phase 4 Wave 2 item 46 (▲, a visible layout change), for your approval before the design note: three ways, A, B and C, no decisions yet. New things in dashed yellow, on the plugin's real screenshot (1x coordinates).
1 · A (recommended): a Bands | List switch; List shows every band in a table where the band editor is (802 x 645, as today)
The window keeps its size and nothing on it moves. A small Bands | List switch goes at the left end of the tab row, which is empty today. Bands is today's editor, unchanged. List puts a table in the same place: one row per band, with its colour and number, power, Type, Freq, Gain, Q, Channel, Dyn (its dynamic range, or —), Group, a temporary Solo and delete. Each value is the shared control: drag it, or click it to type, as on the knobs. Clicking a row selects that band on the graph; double-clicking it opens it in Bands.

Groups (A to D, or none) link bands: moving one moves the rest of its group the same way, Freq by the same ratio, Gain by the same dB and Q by the same ratio, from the handle, the knobs or the list. Hold Alt to move one band on its own. Each grouped handle and tab carries its letter in a small grey tag. Group is a new parameter per band, appended (24), default none, so saved projects load and render as before, to the bit. The handle's right-click menu gets a Group submenu too. Solo is the existing temporary band solo, never saved (§0.3).
