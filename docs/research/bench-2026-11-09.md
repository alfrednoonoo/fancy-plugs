# Head-to-head measurements, 9 November 2026

Fancy Plugs against free competitors, measured with FancyBench (Phase 3 Q1) on the user's PC in one session per category. The reports are in `%USERPROFILE%\VST3-Dev-Tools\bench-results\` on that PC; the figures below are copied from them.

## Setup

- **PC:** 12th Gen Intel Core i7-12650H (16 threads), Windows 11; whether it was on mains or battery wasn't recorded. 48 kHz, 128-sample blocks, stereo.
- **Plugins:**

  | Category | Ours | Competitors |
  |---|---|---|
  | Compressor | Fancy Comp 1.2.0 | TDR Kotelnikov 1.6.7 |
  | EQ | Fancy EQ 1.2.0 | TDR Nova 2.2.3 |
  | Delay | Fancy Delay 1.2.0 | Valhalla Freq Echo 1.2.0, Deelay 1.3.2 |

- **Settings:** the same nominal settings on each, as each plugin displayed them in the report.
- **CPU:** percent of one core in the process call, paced as a DAW would call it, median of 5 runs of 20 s. The ratio to Fancy Comp at its defaults compares across PCs.
- **FancyBench build:** commit `523a091`. Three of its readings were wrong in this build and are left out below:
  - The "All threads" column counted FancyBench's own waiting. Fixed in `2b413a3`.
  - Valhalla's displayed settings were its defaults: it shows its current value whatever it's asked about, though the values were applied.
  - The first delay run's distortion and aliasing were measured while echoes were still arriving. See "Delay".

## Compressor: 4:1 at -20 dB, knee 6 dB, attack 10 ms, release 100 ms

| | Fancy Comp | TDR Kotelnikov |
|---|---|---|
| CPU, mean | 0.79 % | 3.56 % |
| CPU, 99th percentile | 1.8 % | 8.0 % |
| Latency, reported = measured | 0 | 184 samples (3.8 ms) |
| Gain at -10 dBFS, 1 kHz | -5.3 dB | -4.9 dB |
| Gain at -10 dBFS, 50 Hz | -5.8 dB | -1.9 dB |
| THD, 100 Hz at -10 dBFS | -65 dB (0.054 %) | -49 dB (0.34 %) |
| THD, 100 Hz at 0 dBFS | -65 dB | -72 dB |
| THD, 1 kHz at -10 dBFS | -105 dB | -67 dB |
| THD, 1 kHz at 0 dBFS | -105 dB | -80 dB |
| Aliasing, worst relative | -137 dB | -124 dB |
| Clicks, Threshold jumping -40 to -10 dB 20 times a second | none | none |

- **Fancy Comp costs about a fifth of Kotelnikov's CPU** at these settings and adds no latency.
- **Kotelnikov compresses bass less by design:** its detector is filtered, so gain reduction fades out below about 150 Hz. Fancy Comp's detector is open to 20 Hz by default. Raising its Highpass knob to 100-150 Hz gives the same behaviour.
- **Distortion while compressing** comes from the gain moving within each cycle, so it's largest on bass. Fancy Comp is cleaner in three of the four compressing cases. Kotelnikov's 0.34 % at 100 Hz, -10 dBFS, is the only figure near audibility.
- Both report latency correctly and handle fast automation without clicks.

## EQ: +6 dB bell at 1 kHz, Q 1

| | Fancy EQ | TDR Nova |
|---|---|---|
| CPU, mean | 0.49 % | 1.11 % |
| CPU, 99th percentile | 1.2 % | 2.7 % |
| Latency, reported = measured | 0 | 184 samples (3.8 ms) |
| Peak at 1 kHz | +6.00 dB | +4.23 dB, on a baseline of -1.75 dB |
| THD, every frequency and level | -175 to -181 dB | -173 to -183 dB |
| Clicks, Band 2 Gain jumping 0 to 12 dB 20 times a second | none (worst -68.7 dBFS) | 38 bursts, up to -44.9 dBFS |

- **The bells match.** Nova's is +6 dB over its own baseline, with the same width. Its whole output is 1.75 dB lower because "EQ Auto Gain" is on by default, which compensates for the boost's loudness. `eq.json` now turns it off.
- **Fancy EQ uses less than half Nova's CPU** and adds no latency.
- **Both are transparent:** their THD is rounding error.
- **Nova clicks on sudden gain changes; Fancy EQ smooths them.** Host automation is usually gradual, so this shows up with stepped automation or preset changes during playback.

## Delay: 375 ms

**CPU and latency**, with 40 % feedback:

| | Fancy Delay | Valhalla Freq Echo | Deelay |
|---|---|---|---|
| CPU, mean | 0.49 % | 0.33 % | 0.65 % |
| CPU, 99th percentile | 1.19 % | 0.82 % | 1.53 % |
| Latency, reported = measured | 0 | 0 | 0 |

**The echo path**, with no feedback and the echo only (`delay-echo.json`):

| | Fancy Delay | Valhalla Freq Echo | Deelay |
|---|---|---|---|
| THD | -178 to -186 dB | -90 to -109 dB (about 0.003 %) | -162 to -177 dB |
| Aliasing at 0 dBFS | none | -90 dB | none |

- **All three are light,** and all cost less than Fancy Comp at its defaults. Valhalla is the lightest, and Fancy Delay sits between the other two.
- **Fancy Delay and Deelay are bit-clean delay lines.** Valhalla adds a little distortion on purpose, as an analogue-style echo. It's inaudible on one pass but builds up with feedback.
- **The first run's distortion and aliasing were not valid.** With 40 % feedback, echoes kept arriving during the analysis, and at 1 kHz they summed in phase to +5.7 dBFS, which Fancy Delay limited. FancyBench now settles 2 s before measuring and marks readings whose level changes as "not steady".
- **Not yet measured:** clicks while the delay time changes, and the character of the repeats with feedback. `delay.json` now has each plugin's own time parameter for the clicks test.

## What this says about the suite

- **CPU:** in every category measured, ours is as cheap as the free leader or cheaper. Fancy Comp is about 4.5 times cheaper than Kotelnikov, Fancy EQ about 2.3 times cheaper than Nova, and Fancy Delay is in the middle of three light delays.
- **Accuracy:** every plugin reports its latency exactly. Fancy EQ's bell is exact, and our delay and EQ paths are transparent.
- **Automation:** ours didn't click on fast parameter jumps; Nova did.
- **Where competitors differ by design:** Kotelnikov's bass-insensitive detector and Nova's auto gain are deliberate choices. Fancy Comp can do the first with its Highpass knob. Fancy EQ has no automatic gain compensation, which would be a feature to consider.
- **Still to compare:** the paid leaders (Pro-C 3, Pro-Q 4, Timeless 3, EchoBoy), and MultiComp, Verb and FIR, which have no example files yet.
